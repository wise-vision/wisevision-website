01 · install
One container. No broker.
stdio transport. Build the image, point your MCP client at it.
 terminal
$ git clone https://github.com/wise-vision/ros2_mcp.git
$ cd ros2_mcp
$ docker build -t wisevision/ros2_mcp .
# MCP client config
"command": "docker",
"args": ["run", "-i", "--rm",
"wisevision/ros2_mcp:jazzy"]

 agent chat · example
Is the lidar publishing?
