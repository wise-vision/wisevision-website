## section:beats

### See

Your agent lists live topics, services and actions, and reads their message types, with no glue code. {#c:mcp-see}

### Understand

Your agent subscribes to topics, follows action status and queries recorded history, so it can explain what happened. {#c:mcp-understand}

### Operate

Publish, call a service, send an action goal. Or switch all of that off with one environment variable. {#c:mcp-operate} {#c:mcp-readonly}

## section:ros2-mcp

eyebrow: Open source · MPL-2.0

### ROS2 MCP

An MCP server for ROS 2. It speaks stdio, ships as a Docker image and connects Claude, Cursor, Codex or any other MCP client to your robot. {#c:mcp-stdio} {#c:mcp-docker-image} {#c:mcp-clients}

Free for commercial use under the MIT licence. No licence key, no paid tier. {#c:mcp-license} {#c:mcp-free}
