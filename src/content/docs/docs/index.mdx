This is the documentation home for WiseVision products.

- **ROS2 MCP**: an open-source (MPL-2.0) Model Context Protocol server that lets AI agents work with ROS 2 Humble and Jazzy systems. Start with the [quickstart](/docs/ros2-mcp/quickstart/).
- **WiseOS**: in early access. Documentation will follow.

Full documentation is being written. The source code and README live at [github.com/wise-vision/ros2_mcp](https://github.com/wise-vision/ros2_mcp).
